
# 茶叶进销存管理系统改进计划

## 1. 代码重构（优先）
- 提取重复的单位转换逻辑到公共模块
- 统一错误处理机制
- 添加类型提示
- 优化代码结构

## 2. 客户管理功能
- 创建 Customer 类
- 在 ExcelManager 中添加客户相关操作
- 在 TeaInventorySystem 中添加客户管理菜单
- 实现客户的增删改查功能

## 3. 销售记录查询与修改
- 实现销售记录多条件查询（日期、客户、商品）
- 实现销售记录修改功能（带回滚库存）
- 实现销售记录删除/作废功能

## 4. 数据可视化
- 使用 matplotlib 绘制销售趋势图
- 绘制商品销量饼图
- 绘制利润趋势图
- 集成到统计分析模块

## 5. 图形化界面（GUI）
- 使用 tkinter 创建主窗口
- 实现各个功能模块的 GUI 界面
- 集成表格展示和图表展示

## 实施顺序
1. 代码重构
2. 客户管理功能
3. 销售记录查询与修改
4. 数据可视化
5. 图形化界面
