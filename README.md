# 茶叶进销存管理系统

一款专为茶叶行业设计的进销存管理系统，支持商品管理、进货管理、销售管理、供应商管理和统计分析等功能。

## 功能特性

### 1. 商品管理
- **添加商品**：自动分配商品编号，支持详细的商品信息录入
- **查询所有商品**：完整显示库存商品信息，包括茶类、品种、价格、库存等
- **按编号查询商品**：快速定位特定商品
- **修改商品信息**：更新商品属性
- **删除商品**：移除不需要的商品

### 2. 进货管理
- **进货登记**：记录进货数量、单价、供应商等信息
- **历史品种列表**：显示过往进货品种，方便快速选择
- **自动编号**：进货编号自动生成，确保唯一性
- **库存更新**：自动更新商品库存数量

### 3. 销售管理
- **销售登记**：记录销售数量、单价、客户等信息
- **购物车模式**：支持多商品组合销售
- **历史品种列表**：仅显示有库存的品种，支持快速选择
- **自动编号**：销售编号自动生成，确保唯一性
- **折扣销售**：支持实收金额低于应收金额的销售，需用户确认
- **库存扣减**：自动扣减销售商品库存

### 4. 供应商管理
- **添加供应商**：录入供应商基本信息
- **查询所有供应商**：查看所有供应商信息
- **按编号查询供应商**：快速查找特定供应商
- **自动编号**：供应商编号自动生成，确保唯一性

### 5. 统计分析
- **销售统计**：提供多维度统计（按茶类、品种、商品、时间）
- **热销商品排行**：显示销量最高的商品
- **盈利分析**：计算成本、利润、利润率
- **成本利润分析**：考虑销售单位（斤/克）转换的成本利润计算

### 2. 单位转换处理
```python
def calculate_cost(row):
    quantity = row['销售数量']
    unit = row.get('销售单位', '斤')
    
    if unit == '克':
        quantity_in_jin = quantity / 500  # 克转斤
    else:  # 默认是斤
        quantity_in_jin = quantity
    
    return quantity_in_jin * row['成本价']
```
